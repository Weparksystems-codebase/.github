# WePark Systems Engineering

Enterprise software powering **multi-location valet operations, automated monthly billing, transient reservations, and real-time mobile telemetry** across New York parking facilities.

### Core Platform Pillars

- **Real-Time Valet Operations** — Mobile & web ticket issuance, plate/customer lookup, digital QR claim checks, pickup readiness queues, supervisor verification flows, and live staff-to-customer chat.
- **Monthly Accounts & Tax Engine** — Automated 16-stage billing cycles, NYC Commercial Rent & Parking Sales Tax calculation (including 8% NYC resident exemption certificates), online quote wizards, and virtual terminal processing.
- **Partner & Gateway Connectivity** — Webhook-driven reservation ingestion for SpotHero and ParkWhiz, Stripe / CardPointe payment processing, Telnyx SMS delivery, Cloudinary inspection media pipelines, and Firebase push notifications.

### Engineering Stack

- **Backend API**: Node.js, Express, MongoDB / Mongoose, Socket.IO, Stripe, Telnyx, Firebase Admin
- **Web Backoffice & Customer Portal**: Next.js (App Router), React 19, Tailwind CSS v4, TanStack Query, Zustand
- **Mobile Platform**: Flutter (iOS & Android), Riverpod, GoRouter, Hive Offline Sync, Codemagic CI/CD
